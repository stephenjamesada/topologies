# Topologies

This repository stores experimental network topologies I've made for network design practice and overall learning.
Will mainly utilize Cisco Packet Tracer and GNS3.

## Software Used

### Packet Tracer

The simulator, used for creating mockups or sketching out topologies first,
getting the basic idea.
Also used for learning Cisco IOS.
Functions more as a sketchpad.

### GNS3

The emulator which brings that idea to life with real system images.
Packet Tracer topologies will then be remade in GNS3.

## How to Navigate This Repository

To check out a project, navigate to the project directory, listed either as
`gns3/<title>` or `pkt/<title>`.
The project binary itself will be included, as well as its own `README.md`
and image of the topology (its own `assets/images`).
